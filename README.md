## About

**Vaelynth** is the proprietary sub-brand of [VEKENDIAN](https://github.com/vekendian). VEKENDIAN is open-source territory; Vaelynth is where closed-source projects live.

The source code stays private. This organization exists only for what's meant to be public-facing: APIs, documentation, and release information.

## What's Here

- **API**: public endpoints and reference docs.
- **Docs**: usage guides and integration notes.
- **Releases**: changelogs and version announcements.
- **Issues**: bug reports and feature requests for Vaelynth products.
